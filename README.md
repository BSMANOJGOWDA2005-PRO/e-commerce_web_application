# e-commerce_web_applicatio# 🥛 SPS Basavanahalli – Fresh Dairy Products

## 📌 Overview

SPS Basavanahalli is a responsive e-commerce web application for purchasing fresh dairy products and daily essentials. It provides a simple shopping experience with user authentication, product search, shopping cart, profile management, payment options, and order history.

---

## ✨ Features

* 🔐 User Login with OTP verification
* 👤 User Profile Management
* 🛒 Add to Cart & Buy Now
* 🔍 Product Search
* 💳 Multiple Payment Methods

  * Google Pay
  * PhonePe
  * Paytm
  * Cash on Delivery (COD)
* 📦 Order Confirmation
* 📜 Order History
* 📄 Order Details
* 📱 Responsive UI
* 💾 Local Storage for User Profile and Orders

---

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript (ES6)
* Local Storage API

## 🚀 How to Run

1. Clone the repository:

   ```
   git clone https://github.com/your-username/SPS-Basavanahalli.git
   ```

2. Open the project folder.

3. Run `index.html` in your browser.

No installation or backend setup is required.
